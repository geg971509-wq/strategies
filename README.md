# Strategies

量化交易策略资料库。

仓库原先将大量策略 Markdown 文件直接平铺在根目录。为降低根目录噪音、便于浏览和后续维护，策略资料统一收纳到 [`strategies/`](./strategies/) 目录。

## 目录

- [`strategies/`](./strategies/)：完整策略资料库；保留整理前的原始文件名和相对结构。
- [`strategies/README.md`](./strategies/README.md)：原始 FMZ 策略索引与外部策略链接。

## 维护约定

新增策略资料请放入 `strategies/`，不要继续直接堆放到仓库根目录。根目录只保留仓库级入口、许可证、贡献说明以及必要的项目级配置。
